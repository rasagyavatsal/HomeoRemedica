# Security policy

Do not open a public issue containing credentials, private corpus content, signed URLs, internal
object names, or other sensitive information.

Report a suspected exposure privately through GitHub's private vulnerability reporting for this
repository. Include only the minimum information needed to locate the problem and revoke any
affected credential immediately.

Public access to this source repository does not grant access to the HomeoRemedica service, Google
Cloud project, private Storage bucket, or corpus.
